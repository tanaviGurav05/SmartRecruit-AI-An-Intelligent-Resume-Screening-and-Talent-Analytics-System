# SmartRecruit-AI-An-Intelligent-Resume-Screening-and-Talent-Analytics-System

SmartRecruit AI: An Intelligent Resume Screening and Talent Analytics System
Project Overview
SmartRecruit AI is a web-based recruitment management system designed to simplify and improve the hiring process through automated resume screening, skill extraction, candidate-job matching, and talent analytics.
The system helps HR professionals identify suitable candidates by comparing their resume skills with job description requirements. Candidates can register, upload resumes, view their matching scores, identify missing skills, and receive recommendations for improvement.
The platform provides separate dashboards for HR professionals and candidates, making the recruitment process more organized, efficient, and data-driven.
Objectives
•	Automate the resume screening process.
•	Extract technical skills from uploaded resumes.
•	Match candidate skills with job requirements.
•	Calculate candidate-job matching percentages.
•	Identify missing skills and skill gaps.
•	Provide candidate recommendations for improvement.
•	Generate visual analytics to support recruitment decisions.
•	Provide separate dashboards for HR and candidates.
